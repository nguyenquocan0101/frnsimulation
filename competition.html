WORKSHOP RULES

Three scoring criteria

Workshop · no anti-cheat
Correct order

Sort detected blocks by the class values in the English challenge brief. The sample board starts with P2 car.

Steps

Each successful transfer from one slot to another is one step.

Distance

P7 → P2 is 5 slots. No centimetres.

Each team assigns a unique numeric value to: bear, bird, cat, cow, deer, dog, dolphin, elephant, giraffe, horse.

Score = 60% correct order + 25% fewer steps + 15% shorter distance · rounded half up to two decimals.
