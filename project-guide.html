EXAMPLE

A complete program.

Current: P2 = dog, P3 = chicken, P4 = chair, P5 = house, P6 = car. Target: P2 = car, P3 = chicken, P4 = dog, P5 = chair, P6 = house.

main.py
from techcamp_api import TechCamp

def move_block(bot, source, target):
    bot.move_to(source)
    bot.move_down()
    bot.grip()
    bot.move_up()
    bot.move_to(target)
    bot.move_down()
    bot.release()
    bot.move_up()

def main():
    with TechCamp() as bot:
        move_block(bot, "P2", "P7")
        move_block(bot, "P6", "P2")
        move_block(bot, "P5", "P6")
        move_block(bot, "P4", "P5")
        move_block(bot, "P7", "P4")

if __name__ == "__main__":
    main()

HELP

Common fixes.

Missing main()

Define main() with no parameters and call it at the end.

if __name__ == "__main__":
    main()
Syntax error

Check colons, brackets, quotes, and indentation.

Grip or release error

Use move_down() before grip() or release().

Occupied destination

Use P7 as a temporary position.
