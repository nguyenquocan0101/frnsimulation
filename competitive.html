LIVE ARM VISION CHALLENGE

Sort the board with the real arm.

Use camera data, identify the blocks, and finish the correct final arrangement with the lowest total cost.

This page explains the workshop rules. It does not operate the arm, run a model, or store results.

THE FLOW

Four steps

  1. 01Capturecapture()

    Take a camera frame. Each call costs 1 energy; maximum 3 captures.

  2. 02Detectdetect()

    Use your model to return the block positions and identities.

  3. 03Transfermove_to()

    Pick one block and place it in the correct slot. One completed transfer is 1 move.

  4. 04Finishverify()

    Only a correct final arrangement can be ranked.

THE COST POOL

Every action has a fixed weight

FORMULA

total cost = captures × 1 + detects × 3 + moves × 1 + distance × 1

Worked result

2 captures × 1 + 1 detection × 3 + 5 completed transfers × 1 + 10 distance = 20

Lowest total cost wins — if the final arrangement is correct.

ONE TRANSFER

A complete P2 → P5 move

The code below is a reference. It is displayed only; this page has no Run button.

bot.move_to("P2")
bot.move_down()
bot.grip()
bot.move_up()
bot.move_to("P5")
bot.move_down()
bot.release()
bot.move_up()

P2 → P5 = 3 distance

VISION DATA

Capture and detect before moving

Your model can return a list such as this. The page does not execute it.

frame = bot.capture()       # costs 1 energy
objects = bot.detect()      # costs 3 energy
# objects → [{"slot": "P2", "name": "car"}, ...]

Use the board order and count each slot crossed. A shorter route lowers distance.

HOW WINNERS ARE ORDERED

Lowest total cost wins

Teams must first reach the correct final arrangement. If two teams have the same total cost, compare in this order:

  1. lower energy
  2. fewer completed moves
  3. shorter distance

The arm runs in the workshop. Follow the instructor’s safety rules and keep clear of the robot.
